# Metadata and entity decision protocol

Use [T08](../docs/03-technical/t08-metadata-structured-data.md). Establish reviewed public facts, purpose, locale, canonical and owner before generation. If facts missing, defer or omit rather than invent. If document titles/descriptions repeat or conflict, review actual purpose and visible content, then correct owner; no fixed character-count SEO gate. If source/DOM context differs or capture partial, defer absence; account for streaming. If sharing differs, verify target platform, actual image and identity; not search ranking. If markup parses, separately review Schema.org meaning, actual content parity, supported feature requirements and actual display. Multiple nodes/repeated IDs may be legitimate; no blind deduplication. No fake reviews, products, authors, offers or JobPosting. Check feature deprecations; no Google FAQ rich-result goal. Use secure structured serialization, no raw untrusted HTML or remote context resolution. No-change valid. Verify approved representative rollout, rollback, actual search outcomes separately; [patterns](../implementation-patterns/metadata-entities.md).
