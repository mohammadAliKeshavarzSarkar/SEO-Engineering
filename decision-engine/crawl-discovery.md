# Crawl and discovery decision protocol

Use [T05](../docs/03-technical/t05-crawling-robots.md). Start with authorization, origin, crawler policy, intended route purpose and coverage. If robots unavailable or evaluator mismatch, stop/defer own collection; search-engine-specific error handling is not permission. If important public URL/resource disallowed, inspect exact group/rule and fix narrow unintended restriction; do not remove legitimate blocks or expose protected content. If noindex and disallow coexist, distinguish intended removal from crawl control and directive visibility. If sitemap inconsistent, compare reviewed registry/status/canonical/directives and update actual owner only after evidence. If route absent from incomplete crawl, defer absence claims; inspect discovery sources and actual link graph. If broad faceted URL growth or host capacity issue evidenced, measure verified crawler cohorts, meaningful URL families and upstream errors; prioritize source constraints and useful discovery, not arbitrary quotas. For small healthy site no-change is valid. Preserve authorization, real UX, meaningful query parameters and rollback. Recheck matched scoped evidence and actual search outcomes separately. Use [patterns](../implementation-patterns/crawl-discovery.md); no new crawler required.
