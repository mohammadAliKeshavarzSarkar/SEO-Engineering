# SEO engineer learning roadmap

Progress is demonstrated by artifacts and tests, not reading alone. For each competency, research current primary docs, explain tradeoffs, complete a lab, record a decision and validate the result. Use example.org or local fixtures; access real sites only with appropriate permission.

| Level | Competency | Practical assessment |
|---|---|---|
| 1 | HTTP, robots, sitemap, indexing and canonicals | Explain status contract; build and inspect a route inventory |
| 1 | Search intent and on-page basics | Cluster 30 example queries; map intents and write page briefs |
| 2 | JS/SSR/SSG and routing | Compare initial vs rendered DOM; repair a known soft-404 fixture |
| 2 | Information architecture and content quality | Find orphan/overlap candidates and propose a topic network |
| 2 | Structured data and media | Validate an Article graph against visible facts, optimize images |
| 2 | Performance and accessibility | Diagnose LCP/INP/CLS and verify keyboard/mobile behavior |
| 2 | Search reporting | Export and segment query/page metrics with caveats |
| 3 | GA4, Clarity and privacy | Test actual consent behavior, retry-safe accepted business outcome and separate analytics receipt/duplication evidence |
| 3 | Migrations and international | Build redirect mapping and verify hreflang reciprocity |
| 3 | Automation and experiments | Write audit checks, design controlled test, report limitations |
| 3 | Specialty strategy and AI search | Select appropriate modules and distinguish access/citation/referral |

Capstone: audit one real public marketing site, create prioritization and decisions, implement authorized changes, validate production and measure outcomes without overstating causality. Maintain a skills matrix of observed evidence, last practice and gaps. BeatFit is the first intended application; its private evidence stays separate.
