# Cross-module decision examples (fictional)

Use the [review protocol](../../decision-engine/cross-module-review.md). All cases below are authored educational examples, not actual search, deployment, benchmark or provider evidence. No task or action is authorized by these examples.

## A — SPA build vs live delivery vs indexed evidence

A supplied local build artifact has expected route content and canonical. An authorized deployed GET observation instead returns homepage content for that route. An older search inspection record reports a different canonical.

T03 checks host fallback and route behavior; T02 checks matched source/render if needed; T06 interprets current/processed index evidence. These assertions refer to different stages. Do not choose the local success over the live mismatch or declare a current indexing outcome from the older result.

Decision D1: verify exact deployed route/status/content with matched revision and configuration. D2: determine whether fallback correction is justified; hard prerequisite D1's reviewed evidence. D3: claim restored technical delivery only after actual correction and correct deployed assertion. D4: evaluate search processing separately after appropriate evidence becomes available. D3 is not D4. With no deployment authority, propose the scoped correction and hold all writes.

## B — Keyword overlap and existing URL ownership

R04 suggests a tentative cluster because of observed overlapping search results. R06 identifies two useful pages for distinguishable tasks. T07 needs actual equivalence and migration evidence before any redirects; T06 needs the intended representative and actual declarations.

No genuine conflict between candidate grouping and current page ownership is established. Keep both records. Review the task distinction and contrary results before approving consolidation. A high opportunity score cannot replace equivalence, ownership, approval or redirect verification. Continue independent content improvements where authorized. Preserve existing useful URLs.

## C — Consent uncertainty versus reported conversion improvement

An analytics export reports more generate_lead events following a tracking release. Approved business records do not show more accepted leads in the compared cohort. Actual consent/network behavior is unverified.

ANALYTICS separates event count, attribution and backend acceptance. EXPERIMENT cannot assert a growth effect before checking comparable measurement and exposure. If credible exposure is reported, escalate independently using the incident procedure and stop unsafe collection/actions within actual authority. Do not invent a privacy violation from absent evidence. Non-collection under denied consent and an unobserved request are distinct. A proposed analytics fix does not authorize rollout.

## D — Locale checker finding vs platform guidance

A strict local R09 manifest reports an alternate-set discrepancy. Actual reviewed page relationships reveal a legitimate generic-language alias allowed by applicable platform guidance. Reconcile the local policy profile and platform claim; preserve reviewed exception. Do not generate a thin page or change existing URLs just to silence the tool. T06/T07 apply only if a real canonical/index or migration decision is justified.

## E — Cyclic prerequisite and independent urgent concern

A plan says a redirect migration depends on a new canonical registry, while the registry's approval is made dependent on migration success. Split the intended reviewed mapping from post-deployment verification. A reviewed mapping can precede the migration, subject to authorization; actual post-release verification cannot precede it. If the project also reports credible private-data exposure, escalate that separately; do not wait for mapping resolution. No synthetic pass, unattended rollout or automatic incident closure.

These cases demonstrate the intended reasoning pattern. They are not behavioral results. Maintainers must preserve the distinction between educational examples and independently authored held-out evaluation.
